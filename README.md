# Avance Craft

Aplicação web robusta de alta disponibilidade com arquitetura orientada a microsserviços, conteinerização completa e pipelines avançadas de DevOps para governança, resiliência e suporte a ambientes de produção.

🔗 **Live App:** [avance-craft.lovable.app](https://avance-craft.lovable.app)  
🛡️ **Portfólio de Desenvolvimento:** [portfolio.marketingleonardo.com.br](https://portfolio.marketingleonardo.com.br)

---

## 📌 Sobre o Projeto

O **Avance Craft** é uma plataforma corporativa projetada sob rigorosos padrões de engenharia de software e segurança da informação. O repositório destaca-se pela sua infraestrutura completa de CI/CD, documentação técnica detalhada, estratégias de Disaster Recovery (rollback, backup e restore) e ambiente isolado com Nginx e Docker.

---

## ⚡ Diferenciais de Engenharia & DevOps

* **Conteinerização & Servidor Web:** Configurações prontas para produção com Docker, Docker Compose e servidor Nginx (`nginx/`).
* **Segurança e Hardening:** Relatórios e políticas de segurança de infraestrutura (`BACKUP_POLICY.md` e `SECURITY_POLICY.md`).
* **DevOps & Resiliência:** Documentação e automação para rollback (`ROLLBACK_PLAN.md`), planos de rollout (`ROLLOUT_PLAN.md`) e simulações de lançamento (`LAUNCH_SIMULATION_REPORT.md`).
* **Qualidade de Código:** Guias de qualidade automatizados, acompanhamento de Changelog e relatórios de métricas (`QUALITY_GATE_REPORT.md`).

---

## 🛠️ Tecnologias e Ferramentas

* **Frontend & Frameworks:** TypeScript, React, Vite, TanStack Start / Router
* **Backend & Banco de Dados:** Supabase (PL/pgSQL)
* **Infraestrutura & DevOps:** Docker, Docker Compose, Nginx, Shell Scripting
* **Gerenciador de Pacotes:** Bun / npm
* **Desenvolvimento Acelerado:** Lovable
